# C++ University Programming Labs

A collection of C++ programming exercises completed as part of my Information Technologies studies at Moldova State University (USM).

## Laboratory Work No. 1 — Arrays and Matrix Operations

This laboratory work consists of four practical assignments focused on working with arrays, matrices, loops and basic algorithms.

### Task 1 — Finding the Minimum Element

A C++ console application that reads a 5×5 integer matrix and finds its minimum element.

**Concepts:** Two-dimensional arrays, nested loops, conditional statements.

### Task 2 — Matrix Sorting

A C++ console application that reads a 3×3 matrix of floating-point numbers and sorts all its elements in ascending order.

**Concepts:** Sorting, nested loops, element swapping.

### Task 3 — Matrix Operations

A program that calculates the sum of elements smaller than 10 in a 5×5 matrix and transposes the matrix.

**Concepts:** Matrix operations, conditional statements, nested loops.

### Task 4 — Array Randomization

A program that generates a randomized arrangement of integers from 1 to 200, checking that the absolute difference between adjacent elements is at least 5.

**Concepts:** Arrays, randomization, loops, condition checking.

## How to Run

1. Install a C++ compiler, such as g++.
2. Open a terminal in the laboratory folder.
3. Compile a task using `g++ Task1_MinimumElement.cpp -o task1`.
4. Run the compiled program and follow the console instructions.

Each task is an independent console application with its own `main()` function.
